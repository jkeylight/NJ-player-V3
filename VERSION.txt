NJ Player 3.0
Version: 3.0.2
Build: 2026.08.26
Codename: "Enhancement & Encryption"

This is NJ Player 3.0.2 — a fully offline desktop application that combines 
professional-grade video enhancement with military-grade encryption.

Features:
- GPU-accelerated video enhancement (10 presets)
- Real-time audio processing
- AES-256-GCM encryption
- 35-pass secure deletion
- Smart content auto-detection
- Split-screen compare mode
- Modern dark-themed GUI
- Thumbnail grid view
- Resume (recents) panel
- Keyfile-based encryption
- Folder batch encryption
- External subtitle support
- Playlist drag-and-drop reorder
- Multi-language UI
- Shader auto-updater
- Built-in logging

Built on mpv media player with custom shader pipelines.
